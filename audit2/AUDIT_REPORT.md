Material impact: zero-downtime deployments impossible; pod crash loops. | Move migrations to a Kubernetes init container or a Job with an advisory lock (`SELECT pg_try_advisory_lock`). | **P1** | Sync `httpx.Client` blocks FastAPI threadpool on AI critical paths | `apps/api/app/services/llm_service.py` uses `get_sync_http_client()` in `_generate_*` and `stream_*` (11 call sites). A single slow cloud LLM or Ollama request ties up a thread for the full request duration; moderate chat/autocomplete concurrency saturates the pool, producing 503s or large latency spikes. High confidence. Material impact: availability regression under load with no backpressure. | Introduce an async `httpx.AsyncClient` path for production LLM calls, or run synchronous calls inside `await asyncio.to_thread()` with a bounded semaphore. Add per-provider timeouts and a circuit-breaker fallback. [httpx Async Usage](https://www.python-httpx.org/async/) |
| **P2** | No distributed tracing or metrics on critical paths | Grep across `apps/api` returns zero OpenTelemetry, Prometheus, or metrics modules. | **P2** | Orphan background tasks and swallowed exceptions in collaboration relay | `apps/api/app/api/v1/endpoints/collaboration.py:119-126`: `_relay_loop` masks `asyncio.CancelledError` as normal shutdown, restarts via `asyncio.create_task` without joining the predecessor, and leaks pubsub references. 1. **Immediate (P0/P1):** Extract auth FastAPI dependencies to eliminate the 68-site duplication. Split the largest god modules (`RAGService`, `IntelligenceService`, `PdfReader`, `ResearchLibrary`) to reduce regression blast radius. Deploy advisory-lock migration runner before next zero-downtime release.
2. **Next (P2):** Introduce async HTTP client path or bounded threadpool guard for LLM calls. Add Trivy/Grype container scanning and Gitleaks/Semgrep secret scanning to CI. Fix collaboration relay task lifecycle to prevent orphan tasks.
3. **Deferred (P3):** Split health probes, add thread lock to Redis cache, join Tabby daemon thread on shutdown, lower Vitest coverage threshold, extract timeout literals into configuration.
